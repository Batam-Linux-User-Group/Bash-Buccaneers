The Linux Field Guide

What is Linux?

The kernel behind an ecosystem

Linux is an open-source kernel that manages how software uses a computer’s hardware. Distributions build on it to create complete operating systems for desktops, servers, and more.

Explore 24 distros ↓ Learn the basics

What makes a Linux distro?

What is a Linux distribution?

A distro combines the Linux kernel with system utilities, a package manager, and, on desktop editions, a graphical interface.

Why use Linux?

Linux gives you a choice of desktops, workflows, and distributions, with open-source software you can inspect and adapt.

Everyday desktops

6 distros

For work, study, development, and a first Linux desktop.

Ubuntu

A general-purpose desktop with guided installation and a long-term support option. A good starting point for everyday Linux use.

Download ↗ ubuntu.com

Linux Mint

An approachable desktop with a familiar layout. The Cinnamon edition is a good starting point if you are moving from Windows.

Download ↗ linuxmint.com

Zorin OS

A desktop designed for people switching from Windows or macOS. Start with Core for everyday use.

Download ↗ zorin.com

elementary OS

A desktop built around Pantheon, with a consistent visual style and a curated app experience.

Download ↗ elementary.io

Pop!_OS

System76's desktop distribution, with tiling options for multitasking and separate images for some graphics setups.

Download ↗ system76.com

Fedora Workstation

Fedora's desktop edition, with GNOME and a focus on current open-source tools. Well suited to desktop development.

Download ↗ fedoraproject.org

Servers & infrastructure

6 distros

For hosting, cloud workloads, and enterprise development.

Debian

A community distribution with a Stable release for people who prefer a predictable package base on desktops or servers.

Download ↗ debian.org

Rocky Linux

An enterprise Linux distribution in the RHEL ecosystem, commonly used for servers and infrastructure.

Download ↗ rockylinux.org

AlmaLinux

A community-managed enterprise Linux distribution for server and cloud workloads in the RHEL ecosystem.

Download ↗ almalinux.org

openSUSE Leap

The regular-release edition of openSUSE, for desktops and servers that favor a predictable update cadence.

Download ↗ get.opensuse.org

Oracle Linux

An enterprise Linux distribution for on-premises and cloud systems, with Oracle’s Unbreakable Enterprise Kernel available.

Download ↗ yum.oracle.com

CentOS Stream

A continuously delivered distribution that previews changes heading toward the next RHEL minor release.

Download ↗ centos.org

Rolling & hands-on

6 distros

For users who want to choose and configure more of their system.

Arch Linux

A rolling-release distribution that starts with a minimal base and lets you choose and configure the rest of your system.

Download ↗ archlinux.org

EndeavourOS

An Arch-based system with a guided installer. Suits users who want a head start and are comfortable using the terminal.

Download ↗ endeavouros.com

Manjaro

An Arch-based desktop distribution with its own repositories and several preconfigured desktop editions.

Download ↗ manjaro.org

Solus

An independent rolling-release distribution focused on the desktop, with several desktop environments to choose from.

Download ↗ getsol.us

Void Linux

An independent rolling distribution with the runit init system and XBPS package manager, aimed at hands-on users.

Download ↗ voidlinux.org

Gentoo

A highly configurable distribution built around Portage. This download points to Gentoo's minimal installer for 64-bit Intel and AMD PCs.

Download ↗ distfiles-cdn.gentoo.org

Lightweight & specialized

6 distros

For older PCs, minimal systems, privacy, or security testing.

Alpine Linux

A small distribution built around musl and BusyBox, commonly used for containers and minimal server setups.

Download ↗ alpinelinux.org

antiX

A lightweight Debian-based distribution that can run live and is designed to make older computers useful.

Download ↗ antixlinux.com

MX Linux

A Debian-based desktop with graphical MX Tools for common tasks. It offers several desktop editions, including Xfce.

Download ↗ sourceforge.net

Bodhi Linux

A lightweight Ubuntu-based distribution with the Moksha desktop, intended for a small and customizable desktop setup.

Download ↗ bodhilinux.com

Kali Linux

A distribution for authorized security testing, with installer, live and virtual-machine image options.

Download ↗ kali.org

Tails

A live system that runs from USB and routes its Internet traffic through Tor. The installation guide walks you through getting an image.

Download ↗ tails.net
